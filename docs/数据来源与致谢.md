# 数据来源与致谢

本项目使用的开放数据如下，均随源码分发并保留署名：

## 1. 水域多边形数据（`data/water_polygons.json`）

- **来源**：[@geo-maps/earth-waterbodies-100m](https://www.npmjs.com/package/@geo-maps/earth-waterbodies-100m)（[simonepri/geo-maps](https://github.com/simonepri/geo-maps)），数据本体源自 **OpenStreetMap**（© OpenStreetMap contributors）。
- **许可证**：数据按 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1.0/) 授权（见上游 [OpenStreetMap 版权声明](https://www.openstreetmap.org/copyright)）；工具代码按 MIT 许可。
- **用途**：等时圈边界复核的**水域仲裁**。百度算路接口（routematrix / directionlite）对"湖面"与"未建模陆地步道（如滇池绿道）"会返回相同的 `0s/1m` 垃圾数据，仅靠算路结果无法区分。本项目用水体多边形做裁判：采样点落在水体多边形内 → 按水域处理（等时圈内缩）；落在陆地上 → 按未建模步道处理（绿道保留）。
- **预处理**：从全球数据中裁剪中国区域（73°E–135°E, 18°N–54°N），保留对角线 ≥ 3km 的较大水体，坐标由 WGS84 转换为 BD-09（百度坐标系），并按 3 位小数网格建立空间索引。转换脚本见 `backend/_build_water_data.py`。
- **局限**：小于 3km 的水体（小池塘/窄河道）不在仲裁范围内；此类水体对 100m 采样粒度的等时圈影响有限，且百度算路对窄河道能正常返回真实绕行耗时（已实测珠江方向）。

## 2. 底图瓦片

- **来源**：高德地图瓦片（`webrd0{s}.is.autonavi.com`），仅作前端展示底图，不在后端计算中使用。

## 3. 百度地图开放平台

- 地理编码/逆地理编码、POI 检索、路径规划（routematrix/directionlite）均调用百度地图开放平台 Web 服务 API，AK 通过环境变量注入（`.env`），不随源码分发。
