# 模型训练教程：让 Qwen 学会"社区体检解读"

本项目在核心功能之外，**自训了一个领域小模型**：把"15分钟生活圈体检的结构化结果"
转成"自然语言解读 + 选址建议"。本文是保姆级复现教程——你可以在任何一台
**NVIDIA 显卡（8GB 显存及以上）** 的电脑上，从零把模型训练出来并嵌入项目。

> 本次实测硬件：RTX 5060 Laptop 8GB / 32GB 内存 / Windows 11
> 总耗时：环境 30 分钟 + 数据 1 分钟 + 训练约 8 分钟

---

## 0. 整体流程（先看地图）

```
装 Python 3.12 ──> 建训练环境(ai\.venv) ──> 下载 Qwen2.5-1.5B（魔塔）
      │
      ▼
生成训练数据(ai/data_gen.py：项目引擎跑40个城市体检 → JSON+解读文本)
      │
      ▼
QLoRA 微调(ai/train.py：4bit量化 + LoRA，约8分钟)
      │
      ▼
启动推理服务(ai/server.py :8010) ──> 主后端 /api/ai/interpret 代理 ──> 前端"AI解读"按钮
```

---

## 1. 装 Python 3.12（必须 3.12，PyTorch 暂不支持 3.14）

```powershell
winget install --id Python.Python.3.12 --silent --accept-package-agreements
py -3.12 --version   # 验证
```

## 2. 建训练环境

```powershell
cd E:\上海\15min-life-circle
py -3.12 -m venv ai\.venv
ai\.venv\Scripts\python -m pip install --upgrade pip -q

# PyTorch 必须装 CUDA 版（cu128 对应 RTX 40/50 系；老显卡装 cu121 或 cu124）
ai\.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cu128

# 其余依赖（清华源加速）
ai\.venv\Scripts\python -m pip install numpy transformers peft datasets accelerate bitsandbytes modelscope einops sentencepiece -i https://pypi.tuna.tsinghua.edu.cn/simple
```

验证 GPU 可用：

```powershell
ai\.venv\Scripts\python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
# 应输出: True NVIDIA GeForce RTX 5060 Laptop GPU
```

## 3. 下载基础模型（阿里魔塔 ModelScope，国内快）

```powershell
ai\.venv\Scripts\modelscope download --model Qwen/Qwen2.5-1.5B-Instruct --local_dir ai\models\Qwen2.5-1.5B-Instruct
```

下载约 3GB，完成后 `ai\models\Qwen2.5-1.5B-Instruct\` 下有 `model.safetensors`（2.9GB）等 11 个文件。

## 4. 生成训练数据（1 分钟）

```powershell
backend\.venv\Scripts\python -u ai\data_gen.py
```

做了什么：用**项目自身的 Mock 体检引擎**在 20 个城市 40 个真实坐标上跑完整体检，
得到结构化结果（评分/六类得分/设施数/等时圈面积/盲区信息），再用模板渲染成
150-220 字的中文解读。产出：

- `ai\data\train.json`（36 条）—— 训练集
- `ai\data\dev.json`（4 条）—— 验证集
- `ai\data\dataset_info.json` —— 数据集注册信息

> 为什么用 Mock 引擎造数据：确定性、快（40 条约 10 秒）、不消耗百度配额。
> 想扩充数据，改 `ai\data_gen.py` 里 `CENTERS` 列表加坐标即可（换 seed 自动生成不同分布）。

## 5. 训练（约 8 分钟）

```powershell
ai\.venv\Scripts\python -u ai\train.py
```

核心配置（`ai\train.py`）：

| 参数 | 值 | 说明 |
|---|---|---|
| 基础模型 | Qwen2.5-1.5B-Instruct | 1.5B 参数量，8GB 显存可训 |
| 量化 | 4bit NF4（bitsandbytes） | 显存占用降到约 2GB |
| LoRA | rank=16, alpha=32 | 只训练 1.18% 参数（1846 万） |
| 训练轮数 | 6 epochs | 36 条数据，约 27 步 |
| 学习率 | 2e-4 cosine | 标准 SFT 配置 |

训练日志会打印每步 loss（从 ~1.8 降到 ~0.3），产物在：

```
ai\models\qwen15min-lora\   （adapter_model.safetensors + adapter_config.json + tokenizer）
```

## 6. 启动 AI 推理服务并联动主项目

```powershell
# 终端 1：启动 AI 服务（加载微调模型，端口 8010）
ai\.venv\Scripts\python -u ai\server.py

# 终端 2：主服务已运行（http://127.0.0.1:8000）时无需重启，自动代理
```

验证：

```powershell
Invoke-RestMethod http://127.0.0.1:8010/api/ai/health
# status=ok, model_loaded=true
```

浏览器打开 http://127.0.0.1:8000 → 点"开始体检" → 结果区出现
**"✨ AI 解读与选址建议"** 按钮 → 点击，约 3-10 秒生成一段解读。

## 7. 常见问题

| 现象 | 原因与解决 |
|---|---|
| `torch.cuda.is_available()` 为 False | 显卡驱动太旧，升级到 550+；或换 cu121/cu124 的 torch 重装 |
| 4bit 加载报 bitsandbytes 错误 | 显卡需支持 CUDA；确认安装的是 `cu128` 版 torch 与最新 bitsandbytes |
| 训练时显存不足（OOM） | 把 `per_device_train_batch_size` 改 1，`gradient_accumulation_steps` 改 8 |
| AI 按钮提示"AI 解读服务未就绪" | `ai\server.py` 没启动，或模型目录 `ai\models\qwen15min-lora` 不存在（没训练） |
| 主服务重启后按钮报错 | 主后端无需重启；确认 8010 端口 AI 服务仍在运行 |
